# Historical engineering snapshots

This folder preserves dated pre-Footprint-Lens engineering snapshots supplied or
found during the audit. Their old `Carbon Saathi` identifiers are retained so
archive paths and hashes are not silently changed. They are not the canonical
current application and must not be used as current product naming or as proof of
formal deliverable completion.

The canonical current review build is in [`../application/`](../application/),
with the provisional user-facing name **Footprint Lens**.
