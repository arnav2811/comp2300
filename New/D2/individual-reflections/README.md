# D2 individual-reflection evidence pack

The official specification requires an individual Markdown reflection of no more
than 200 words. A future reflection must describe the named student's actual
contribution, effect, theory/process, improvement and evaluation of previous
changes. These files are evidence-capture templates, not completed submissions.

Each student must replace prompts with their own verified experience and remove
anything they did not do. No one else's role description can establish a
student's attendance, hours, feelings, review or implementation contribution.
