# D2 meeting records

The official COMP2300 specification requires actual weekly minutes using the
course template. Future meetings cannot be written as completed minutes before
they happen. This folder contains agendas and evidence-capture forms only until
the team supplies confirmed attendance, discussion, decisions and actions.

After each real meeting, copy the official template into this folder, complete
it from the actual notes, obtain team accuracy checks and record Blackboard
submission separately. Do not replace an agenda with invented outcomes.
