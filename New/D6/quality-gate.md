# D6 final-increment quality gate

| Gate | Required evidence | Result |
|---|---|---|
| Build | Clean checkout, documented JDK/JavaFX/tool versions, zero build errors | Pending actual build |
| Functional | Every selected story has acceptance evidence | Pending implementation |
| Automated tests | Component, integration, boundary and regression results | Pending implementation |
| Accessibility | Keyboard/focus, readable labels, errors and contrast reviewed | Pending real UI review |
| User guide | Setup/use/troubleshooting match delivered application | Pending final UI |
| Project management | Burndown, tasks, hours/DoD where required, review/retrospective | Pending real records |
| Package | PDF/archive/link open correctly | Pending final artefacts |

The result column must be completed with actual commands, files and reviewer/date;
“Pending actual build” is not a test failure or a fabricated pass.
