# D7 — Evaluation Report

**Official deadline:** 3 May 2027 at 16:00 in the supplied schedule.  
**Status:** Report and analysis package drafted for review; participant evidence pending.

## Required report sections

1. Evaluation materials and recruitment.
2. How the actual evaluation was conducted.
3. Data cleaning and analysis method with justification.
4. Results that accurately reflect the collected data.
5. Discussion, limitations and recommendations.

The report must not claim carbon reduction or population generalisation unless the
actual design and data support that claim. A planned protocol or synthetic fixture
cannot be written as a participant finding.

The integrated report is [`report.md`](report.md). It distinguishes engineering
checks from the actual summative evaluation still required by the course.
