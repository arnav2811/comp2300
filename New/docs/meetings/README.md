# Meeting records

Store actual minutes using the official COMP2300 template supplied with the
course materials. Include date, attendees/apologies, agenda, progress, decisions,
risks, action owners/dates/status, and next meeting. Review accuracy before
submission to Blackboard.

Only confirmed meetings belong here. Future agendas are labelled as agendas;
they are not minutes. `2026-10-15-week06-minutes.pdf` and
`2026-10-22-week07-minutes.pdf` are supplied records copied from the workspace;
their Blackboard submission status remains unverified.
