# Deliverable control index

The official specification is the authority for each deliverable. Each folder
contains planning/evidence controls; a matrix marked `Planned` is not a claim of
completed work.

| Deliverable | Official purpose | Current control |
|---|---|---|
| D1 | Understanding the Problem Space | [`D1/`](D1/) baseline and rubric review |
| D2 | Conceptual Design | [`../../D2/`](../../D2/) working design and rubric gate |
| D3 | Evaluation Plan, Architectural Design and Technical Setup | [`../../D3/rubric-matrix.md`](../../D3/rubric-matrix.md) |
| D4 | Increment 1 | [`../../D4/rubric-matrix.md`](../../D4/rubric-matrix.md) |
| D5 | Increment 2 | [`../../D5/rubric-matrix.md`](../../D5/rubric-matrix.md) |
| D6 | Increment 3 | [`../../D6/rubric-matrix.md`](../../D6/rubric-matrix.md) |
| D7 | Evaluation Report | [`../../D7/rubric-matrix.md`](../../D7/rubric-matrix.md) |

Every final report must also cover the general requirements: work completed,
specific tasks, project management, tools/techniques, and product/process
reflection.
