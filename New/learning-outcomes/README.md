# Learning outcomes register

> **Status:** mixed register. Rows marked fictional are illustrative learning
> records for rehearsal. Rows marked verified refer only to observable checks or
> supplied artefacts, not invented student experiences.

The project uses learning outcomes as a change mechanism: each record identifies
what changed, what prompted the learning, which assumption was revised, what the
next version changed and how the lesson applies forward.
