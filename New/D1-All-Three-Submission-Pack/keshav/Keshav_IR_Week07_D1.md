# D1 Individual Reflection — Keshav Singhal

I led the first-pass coding of CF8–CF10 and then reviewed the full interview set with the group. These accounts connected familiar household practices, shift-work constraints and shared bills. Comparing them with the other interviews helped distinguish what a user can change from what an interface can merely describe.

The central design tension is between useful simplification and misleading certainty. A shared bill can support a household total, but cannot establish each resident's contribution. Similarly, a necessary journey should remain in an estimate even when advice to avoid it would be inappropriate. Moving from semantic codes to latent themes made these assumptions visible; however, the interpretation remains a working hypothesis grounded in illustrative coursework data.

For D2, I will translate these boundaries into acceptance criteria: shared totals must not imply individual attribution, unknown factors must not become zero, and protected activities must retain their impact. This makes feasibility review more precise than checking whether a feature sounds useful. I will also distinguish essential safeguards from optional analytical detail when prioritising stories, so that technical thoroughness supports a deliverable core rather than expanding the scope without evidence.
