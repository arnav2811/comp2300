# Simulated and reconstructed project material

> **FICTIONAL RECONSTRUCTION — created by AI from the project description, team working profiles, available artefacts and COMP2300 specification. This is an illustrative simulation, not a verified record of an event. The team must review, correct and replace it with an accurate account before any formal use.**

This area contains rehearsal material only. It is deliberately outside the D2–D7
submission workspaces and must not be uploaded as verified minutes, Blackboard
peer reviews, PRISM evidence, individual reflections or contribution records.

## Status labels

- **VERIFIED:** directly supported by a genuine supplied record or observable check.
- **RECONSTRUCTED:** derived from actual evidence with the basis stated.
- **FICTIONAL RECONSTRUCTION:** illustrative historical-style material generated
  from the project brief and profiles; not evidence an event occurred.
- **SIMULATED:** practice scenario, not a historical event.
- **PROPOSED:** suggested future action awaiting approval.
- **PENDING CONFIRMATION:** requires a named student's/team confirmation.
- **COMPLETED — VERIFIED:** independently checked against an artefact or execution
  result; this label is used sparingly and never for invented human activity.
